# Bug Report: Ошибка при вводе некорректного email на странице логина

## Общая информация

- **Проект:** Web Application (учебный pet-проект)
- **Модуль:** Авторизация (Login)
- **ID бага:** BUG-LOGIN-001
- **Severity:** Medium
- **Priority:** High
- **Статус:** New
- **Окружение:**
  - ОС: Windows 10
  - Браузер: Chrome 127
  - URL: https://example-app.com/login

## Шаги воспроизведения

1. Открыть страницу логина: https://example-app.com/login
2. В поле «Email» ввести некорректное значение: `test@invalid`
3. В поле «Password» ввести любое значение, например: `Test1234!`
4. Нажать кнопку «Log In».

## Ожидаемый результат

- Система отображает сообщение об ошибке валидации email, например:  
  «Please enter a valid email address.»
- Авторизация не выполняется, пользователь остаётся на странице логина.

## Фактический результат

- Сообщение об ошибке валидации не отображается.
- Происходит попытка отправки формы и переход на страницу ошибки сервера (500 Internal Server Error).

## Дополнительная информация

- Проблема воспроизводится стабильно (3 из 3 попыток).
- В консоли браузера (DevTools → Console) отображается ошибка JS:  
  `Uncaught TypeError: Cannot read properties of undefined (reading 'validate')`
- В Network (DevTools → Network) запрос на `/api/login` возвращает статус 500.

## Вложения

- Скриншот страницы с ошибкой (при наличии)
- Скриншот вкладки Network с запросом и статусом 500
