# Checklist: Авторизация в web-приложении

## Общая информация

- **Проект:** Web Application (учебный pet-проект)
- **Модуль:** Авторизация (Login)
- **Дата:** 16.08.2026
- **Автор:** SharLodka
- **Тип тестирования:** Functional Testing, Smoke Testing, Regression Testing
- **Окружение:** Windows 10, Google Chrome

## Предусловия

- Открыта страница авторизации.
- Создан активный тестовый пользователь:
  - Email: `user@example.com`
  - Password: `Test200!`

## Функциональные проверки

- [ ] Страница авторизации открывается без ошибок.
- [ ] На странице отображается поле для ввода email / логина.
- [ ] На странице отображается поле для ввода пароля.
- [ ] На странице отображается кнопка входа (`Log In` / `Войти`).
- [ ] При вводе корректных email и пароля пользователь успешно авторизуется.
- [ ] После успешной авторизации пользователь перенаправляется на главную страницу или в личный кабинет.
- [ ] После успешной авторизации отображается имя пользователя, профиль или другой признак активной сессии.
- [ ] Нажатие клавиши `Enter` отправляет заполненную форму авторизации.
- [ ] Пользователь может выйти из аккаунта через функцию Logout / Выйти.
- [ ] После выхода пользователь не может открыть защищённую страницу без повторной авторизации.

## Проверки валидации полей

- [ ] При пустом поле email / логина форма не отправляется.
